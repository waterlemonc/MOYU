# Planet textures

These texture files are copied unchanged from the Three.js r160 example assets:

- `earth-day.jpg`: https://raw.githubusercontent.com/mrdoob/three.js/r160/examples/textures/planets/earth_atmos_2048.jpg
- `earth-night.png`: https://raw.githubusercontent.com/mrdoob/three.js/r160/examples/textures/planets/earth_lights_2048.png
- `moon.jpg`: https://raw.githubusercontent.com/mrdoob/three.js/r160/examples/textures/planets/moon_1024.jpg

Upstream repository: https://github.com/mrdoob/three.js/tree/r160/examples/textures/planets

The Three.js repository license is retained at `assets/vendor/THREE-LICENSE.txt`. Other planet surfaces, clouds, Saturn's rings and the background are generated in code; no remote image service is used by the published page.
